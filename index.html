03

Featured project

FeedLens
Full-stack video platform with a transparent recommendation engine

A video-sharing platform built to solve a real frustration with black-box recommendation algorithms — every viewer can see and choose which ranking mode is shaping their feed. Built solo, end-to-end, across three services.

.NET 8 API
Core backend, auth and data layer
Angular 19
Frontend client application
Python / FastAPI
ML microservice for feed ranking
AWS S3 + Redis
Video storage and caching layer

Auth & security: JWT-based authentication with secure, presigned upload URLs direct to S3 — no video traffic passes through the API server.

Recommendation engine: Five distinct algorithm modes (Focal, Prism, Spectrum, Flare, Drift), each surfaced transparently in the UI so users understand why a video was recommended.

Deployment: Distributed across Railway (API), Vercel (frontend), Azure SQL (data) and AWS S3 (media) — a deliberate multi-cloud setup to demonstrate deployment flexibility.

Roadmap: Azure Cognitive Search for discovery, Azure Service Bus for async processing, and AWS Lambda for on-upload thumbnail generation.
